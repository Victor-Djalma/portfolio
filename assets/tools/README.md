# Logos de tecnologias

Arquivos armazenados localmente; o site não consulta serviços de imagens externos durante a navegação. Os caminhos estão centralizados em `PORTFOLIO.toolLogos`, no arquivo `data.js`.

## Origem e atribuição

- [Devicon](https://github.com/devicons/devicon): AWS, Oracle, Microsoft Azure, Windows, Linux, Python, Flask, JavaScript, PowerShell e Kibana, versões `original`. A licença da coleção foi preservada em `DEVICON-LICENSE.txt`.
- [Grafana](https://github.com/grafana/grafana): ícone original obtido diretamente do repositório oficial do projeto.
- [selfh.st Icons](https://github.com/selfhst/icons), por selfh.st: n8n, Wazuh, pfSense e Zabbix, versões padrão, sem recoloração. Coleção sob [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/); cópia em `SELFHST-LICENSE.txt`.
- [Nmap](https://nmap.org/): PNG original de 256 × 256 px, fornecido pelo site do projeto.
- [Fortinet](https://www.fortinet.com/): SVG original da marca, usado para identificar FortiGate, sem alteração de cor ou proporção.
- [KeePass](https://keepass.info/): ícone oficial do site, extraído do ICO para PNG de 32 × 32 px e exibido no tamanho nativo.

`sources.json` registra a URL exata de cada download. Windows e Windows Server compartilham o símbolo Windows; OCI usa a marca Oracle. Os arquivos SVG e PNG baixados foram mantidos sem recoloração. A conversão do ICO KeePass preserva seus pixels e canal alfa.

Os nomes e marcas pertencem a seus respectivos titulares e identificam as tecnologias listadas no portfólio. TCP/IP, VLANs, switching, routing, VPN e APIs REST usam ícones conceituais locais, sem atribuir um logo de marca a um padrão genérico.

Os badges de certificação não vieram destas coleções: todos os quatro arquivos foram enviados pelo titular e ficam em `assets/certifications/`.
